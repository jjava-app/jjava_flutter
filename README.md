# 심화 프로젝트 1  OPEN AI를 활용한 Springboot 기반 개발앱 : 블록 코딩 앱

- Flutter로 개발한 블록 코딩 앱 짜바(JJAVA)입니다.
- 고난이도의 블록코딩을 통한 사용자의 코딩 능력 향상과 모바일/태블릿 기기를 통한 접근성 높은 서비스를 기대합니다.

<br>

## 주요 기능


| 카테고리         | 구현 기능                                         |
|--------------|-----------------------------------------------|
| **홈**        | 이번 주 랭킹 / 내 랭킹 / 지난 학습 보기               |
| **워크스페이스**     | 개인 워크스프에스 / 블록코딩 및 컴파일           |
| **학습** | 문제 목록 / 문제 풀기 / 문제 상세보기 / 문제 컴파일 및 AI 첨삭                |
| **지난 학습**     | 푼 문제 AI 첨삭 다시보기 / 푼 문제 AI 리팩토링 JAVA코드 다시보기 / 푼 문제 내용 및 제목 다시보기             |
| **로그인 인증**    | 앱 이메일 로그인 및 이메일 인증 구현 / 카카오 OAUTH 로그인 구현 / 구글 OAUTH 로그인 구현 / 네이버 OAUTH 로그인 구현 |
| **마이페이지**    | 내 정보 수정 / 카카오, 네이버, 구글 계정 연동                                      |
| **온보딩**   | 사용자 튜토리얼 화면                    |
